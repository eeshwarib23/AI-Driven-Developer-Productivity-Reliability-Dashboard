# AI-Driven Developer Productivity & Reliability Dashboard (Phase 1)

Interactive web demo that simulates common developer workflow actions (write code, commit, fix bugs, miss deadlines) and converts them into real-time metrics + AI-style insights.

## Live Demo
- Replit: (https://replit.com/@balusueeshwari/AI-Driven-Developer-Productivity-Reliability-Dashboard?v=1)

## What it does
- Simulates developer actions through button clicks
- Tracks real-time metrics:
  - Productivity score
  - Reliability score
  - Failure rate
  - Avg duration and P95 duration
  - Throughput (actions per minute)
- Generates explainable “AI-style” insights (rule-based in Phase 1)
- Shows both a dashboard view and raw JSON for transparency

## Tech Stack
- Backend: **Python + FastAPI**
- Frontend: **HTML + JavaScript**
- Hosting/Demo: **Replit**
